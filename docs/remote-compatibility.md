# Remote behavior and updates

Remote functions can change after purchase through TV firmware, remote firmware, or the manufacturer's input components. A factory manual is an optional reference, not proof of present behavior.

A limited Android TV validation report describes that later updates added double Volume-minus to mute and continuous adjustment while holding Volume-plus or Volume-minus. This is recorded as user-reported current behavior, not a universal promise for every Xiaomi remote or firmware.

SwiftOS keeps native volume, power, voice and media events with Android. Test the actual remote before and after launcher changes, and repeat checks after a TV or remote update. The manual review remains a separate optional test; an unavailable manual does not block normal scanning or compatible standard controls.

Evidence stays distinct: observed TV capabilities; the user's actual button tests; manufacturer manual statements; community reports. Unknown remote software versions remain unknown. A manual must never override a working firmware-added shortcut or justify automatic button remapping.
